# E-Commerce Sales Analytics

This project demonstrates a complete end-to-end sales analytics workflow in Python using object-oriented programming, pandas, NumPy, and visualization libraries.

## What it includes
- Customer, Product, and Order classes
- CSV loading for customers, products, and orders
- Dataset merging and revenue calculation
- Discount handling with NumPy broadcasting
- Product-wise, customer-wise, and monthly sales analysis
- Charts for trend analysis and spending insights

## How to run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the analysis script:
   ```bash
   python ecom_analytics.py
   ```
3. Charts will be saved in the `output/plots` folder.
